# Documentation de skarden-web

## Ordre de lecture

1. [developpement.md](developpement.md) — l'arborescence, les commandes, les pièges d'outillage.
2. [invariants.md](invariants.md) — `INV-1`, `INV-2`, les contraintes non négociables.
3. [pratiques.md](pratiques.md) — la lecture des fiches, les tests, les erreurs, la mise en page, le cycle de livraison.
4. [clean-code.md](clean-code.md) — comment s'écrit l'intérieur d'une unité, et ce que l'outillage fait respecter.
5. [conventions.md](conventions.md) — nommage, langue, commentaires, commits.

## Ce qui n'est pas ici

- **Les décisions produit** — le format des fiches, ce que le site montre et comment on y navigue : le référentiel de cadrage `ssk-it/skarden-cadrage`. Le consulter par le skill `consulter-referentiel` avant toute évolution fonctionnelle.
- **Les fiches et leur format** : le dépôt de données [sskorupski/skarden](https://github.com/sskorupski/skarden), qui déclare ses collections dans `referentiel.yml` et leurs champs dans `schemas/`.
