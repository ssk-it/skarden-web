# Skarden — web

Que faut-il à chacune de mes plantes, et qu'ai-je appris en les cultivant ?

Le site statique qui présente et parcourt les fiches de Skarden. Les fiches vivent dans le dépôt de données public [sskorupski/skarden](https://github.com/sskorupski/skarden) : ce site les lit, il n'en est pas la source. Les décisions produit se prennent dans le référentiel de cadrage `ssk-it/skarden-cadrage`.

## Lancer

```bash
pnpm install
pnpm dev
```

La documentation technique commence à [docs/README.md](docs/README.md).
